# Getting Started — Day 0 → Day 1

This file walks you through bringing the project from a clone to a running app on your local machine. Estimated time: **30 minutes** (assuming PHP, Composer, MySQL, Redis are installed).

> If you only need the cheat-sheet, jump to the [TL;DR](#tldr) at the bottom.

---

## 0. What you just received

This repository was scaffolded with the production-grade Laravel 12 architecture, **but** the Laravel framework files themselves (the `vendor/`, `bootstrap/`, `config/`, `public/`, `resources/`, `tests/` directories) still need to be generated by Laravel's installer. We do this to avoid bloat in version control — the standard `laravel new` command rebuilds them on your machine in seconds.

So Step 1 below is **"install Laravel 12 on top of this folder"** and merge our handwritten code in.

---

## 1. Install prerequisites

### Windows (PowerShell)
```powershell
winget install --id=PHP.PHP.8.3 -e
winget install --id=Composer.Composer -e
winget install --id=OpenJS.NodeJS.LTS -e
winget install --id=Oracle.MySQL -e
winget install --id=Memurai.Memurai-Developer -e   # Redis on Windows
winget install --id=Git.Git -e
```

### macOS (Homebrew)
```bash
brew install php@8.3 composer node mysql redis git
brew services start mysql
brew services start redis
```

### Linux (Ubuntu / Debian)
```bash
sudo apt update
sudo apt install -y php8.3 php8.3-cli php8.3-mbstring php8.3-xml php8.3-bcmath \
    php8.3-mysql php8.3-redis php8.3-gd php8.3-zip php8.3-intl php8.3-curl \
    composer nodejs npm mysql-server redis-server git
```

### Verify
```bash
php -v          # PHP 8.3.x
composer -V     # 2.7+
node -v         # v20+
mysql --version
redis-cli ping  # PONG
```

## 2. Create the Laravel 12 project skeleton

From the **parent** folder of `kanban/`:

```bash
composer create-project laravel/laravel kanban-tmp "^12.0"
```

Now copy the framework files we don't track into our project:

### PowerShell (Windows)
```powershell
$src = "kanban-tmp"
$dst = "kanban"
$folders = @("bootstrap","config","public","resources","storage","tests")
$files   = @("artisan","vite.config.js","package.json","tsconfig.json","phpunit.xml")

foreach ($f in $folders) {
    if (Test-Path "$src\$f") {
        Copy-Item "$src\$f" "$dst\" -Recurse -Force
    }
}
foreach ($f in $files) {
    if (Test-Path "$src\$f") {
        Copy-Item "$src\$f" "$dst\" -Force
    }
}
Remove-Item -Recurse -Force $src
```

### macOS / Linux
```bash
SRC=kanban-tmp
DST=kanban
for f in bootstrap config public resources storage tests; do
  [ -d "$SRC/$f" ] && cp -R "$SRC/$f" "$DST/"
done
for f in artisan vite.config.js package.json tsconfig.json phpunit.xml; do
  [ -f "$SRC/$f" ] && cp "$SRC/$f" "$DST/"
done
rm -rf "$SRC"
```

> Important: Do **NOT** overwrite the `app/`, `database/`, `routes/`, `composer.json`, `.env.example`, `docker/`, `docs/`, or `README.md` from our scaffold. They contain our production code.

## 3. Install dependencies

```bash
cd kanban
composer install
npm install
```

If composer complains about additional packages from our `composer.json`, run:
```bash
composer update --with-all-dependencies
```

---

## 4. Configure environment

```bash
cp .env.example .env
php artisan key:generate
```

Edit `.env` and set:

```env
DB_DATABASE=kanban
DB_USERNAME=root
DB_PASSWORD=your-mysql-password
```

Create the database:
```bash
mysql -u root -p -e "CREATE DATABASE kanban CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

---

## 5. Install Reverb (real-time WebSocket server)

```bash
php artisan install:broadcasting
# When prompted, choose "Reverb"
```

This adds Reverb config to `.env` automatically.

---

## 6. Install Sanctum (API auth)

```bash
php artisan install:api
```

This publishes Sanctum's config and migration.

---

## 7. Install Breeze (auth scaffolding — Vue + Inertia)

```bash
composer require laravel/breeze --dev
php artisan breeze:install vue --ssr
npm install
```

---

## 8. Run migrations + seed demo data

```bash
php artisan migrate --seed
```

You should see output ending with:
```
Seeded demo user: demo@kanban.test / password
```

---

## 9. Create storage symlink

```bash
php artisan storage:link
```

---

## 10. Run the app (4 processes)

Open **4 terminals**:

```bash
# Terminal 1 — HTTP
php artisan serve

# Terminal 2 — Queue worker
php artisan queue:work --tries=3

# Terminal 3 — Reverb WebSocket server
php artisan reverb:start

# Terminal 4 — Vite (frontend HMR)
npm run dev
```

Visit: **http://localhost:8000**

Log in with: `demo@kanban.test` / `password`

---

## 11. Verify the API works

```bash
# Login and get a token
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@kanban.test","password":"password"}'

# Response includes a token. Use it:
TOKEN="paste-token-here"

# List workspaces
curl http://localhost:8000/api/v1/workspaces \
  -H "Authorization: Bearer $TOKEN"
```

## Common Issues

| Problem | Fix |
|---|---|
| `SQLSTATE[HY000] [1045]` | Wrong MySQL password in `.env` |
| Redis connection refused | `redis-server` not running |
| `reverb:start` says port 8080 in use | Change `REVERB_PORT` in `.env` |
| `php artisan` says "No application encryption key" | Run `php artisan key:generate` |
| Migration fails on `lists` table | MySQL reserved word — our migration uses backticks; ensure MySQL ≥ 8 |
| 419 CSRF on API | API uses Sanctum bearer token, not CSRF. Pass `Authorization: Bearer ...` header. |
